## 🌐 Xem Trực Tiếp Bằng GitHub Pages

Sau khi push lên GitHub, bạn chỉ cần:
1. Vào **Settings** của repository trên GitHub.
2. Chọn mục **Pages** ở cột bên trái.
3. Ở phần **Branch**, chọn `main`, thư mục `/ (root)` và nhấn **Save**.
4. Sau 1-2 phút, bạn sẽ có link chạy web trực tiếp vĩnh viễn:
   ```
   https://tuyenhk05.github.io/cvT/
   ```
